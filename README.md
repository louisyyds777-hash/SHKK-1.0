# 手绘K线 1.0 版本（SHKK-1.0）

把每一根K线还原为它时间周期内的**完整价格运动轨迹**：单根K线画成「开 → 高 → 低 → 收」的四点手绘折线（阳线 开→低→高→收，阴线 开→高→低→收），红=多、绿=空，底部对齐量能，多根连续排列、彼此留间隔不相连——像在手绘笔记本上看盘。

## 功能

- **真实A股数据**（免费接口，零token）：
  - 腾讯主源：分钟K线（5/30/60分钟，≤800根）、日K全史（不复权真实价格）、周线/月线、报价（名称解析）
  - 新浪弱源：分钟历史打底（约1969根）、全部A股列表（搜索池，7天缓存）
  - 未收盘K线不进图；本地缓存 + 60秒节流增量更新
- **6个周期**：5分钟 / 30分钟 / 60分钟（=1小时）/ 日线 / 周线 / 月线
- **5种画风**：铅笔手绘 / 记号笔 / 荧光笔 / 方格纸 / 毛笔，随时切换
- **TV式画线工具**：光标/直线/射线/水平线/矩形/画笔/文本/斐波那契回调；拖动或两点点选；磁吸OHLC；选中浮动样式条（8色/粗细/实虚线）；Ctrl+Z撤销；按股票持久化
- **股票搜索 + 自选库**：全市场A股按代码/名称搜索；自选本机保存
- **自由缩放平移**：滚轮以鼠标为中心缩放、按住四方向拖动、双击复位
- **叠加蜡烛**：无 / 完整蜡烛 / 仅实体圆柱（无上下影线）
- **导出PNG**（含画线）
- **桌面双击即用**：`启动手绘K线.bat`（pythonw 无窗口启动 + 自动开浏览器 + 桌面快捷方式）

## 快速开始

```bash
pip install requests          # 唯一依赖
python server.py              # 或双击 启动手绘K线.bat
# 浏览器自动打开 http://127.0.0.1:8791/
```

桌面使用：把 `启动手绘K线.bat` 发送快捷方式到桌面（配 app.ico 图标）即可双击启动；重复双击不会开第二个服务。

## 项目结构

```
├── server.py              # 本地服务（stdlib，零框架）：kline/search/name/drawings API + 静态页
├── data_source.py         # 数据层：腾讯主源+新浪打底+缓存+未收盘剔除+周月线
├── drawings_store.py      # 画线持久化（data_store/drawings/）
├── static/
│   ├── index.html         # 主页面（渲染/交互/画线工具）
│   └── rough.js           # 手绘风渲染库（roughjs 4.6.6，本地内嵌）
├── 启动手绘K线.bat          # 桌面启动器
├── app.ico                # 图标
├── 手绘K线-演示.html        # 离线单文件演示（模拟数据，无需服务）
├── 手绘K线-单根比例选择.html # 单根高宽比方案对比页（A~E五档）
├── demo_template.html      # 演示页源模板
└── ratio_template.html     # 比例选择页源模板
```

## 说明

- 单根轨迹的「高度」由该K线真实波幅决定（数据本身）；「宽度」（高宽比形态）可调，见比例选择页。
- 数据获取的实施路径参考了 [chanlun-DA](https://github.com/louisyyds777-hash/chanlun-DA.v1.0) 项目（腾讯/新浪接口用法与字段顺序坑），画线工具的交互规范（两点点选/磁吸/浮动样式条）亦对其前端做了对齐。
- rough.js 基于 [roughjs](https://github.com/rough-stuff/rough) (MIT License)。
